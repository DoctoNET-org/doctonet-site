Tutoriel numérique

Installer une application sur son smartphone

Télécharger une application gratuitement depuis l'App Store (iPhone) ou le Play Store (Android), en toute sécurité.

🔒 Les applications des stores officiels sont sûres
L'App Store et le Play Store sont les boutiques officielles d'Apple et de Google. Toutes les applications qui s'y trouvent ont été vérifiées. Vous ne risquez rien en téléchargeant depuis ces stores — c'est comme entrer dans une grande surface plutôt qu'acheter dans la rue. Si une application est gratuite, vous n'avez pas à saisir votre numéro de carte bancaire.
ℹ️ Ce tutoriel explique comment installer n'importe quelle application. Choisissez votre type de téléphone ci-dessous.

Étape 1 — Ouvrir l'App Store

1
Trouvez l'App Store sur votre écran d'accueil
L'App Store est une icône bleue avec un « A » blanc formé par un crayon. Elle est installée d'office sur tous les iPhones — vous ne pouvez pas la supprimer.
Si vous ne la voyez pas, balayez l'écran vers le bas et tapez « App Store » dans la barre de recherche
2
Appuyez sur l'icône pour ouvrir l'App Store
Un simple appui suffit. L'App Store s'ouvre sur la page d'accueil.

1
Appuyez sur « OBTENIR »
Le bouton bleu « OBTENIR » lance le téléchargement. iPhone peut vous demander de confirmer avec Face ID (regardez l'écran) ou Touch ID (posez le doigt sur le bouton).
Pour une application gratuite, aucune carte bancaire n'est demandée
2
Attendez la fin du téléchargement
Un cercle de progression apparaît à la place du bouton. Le téléchargement dure généralement moins d'une minute en Wi-Fi.
3
Appuyez sur « OUVRIR »
Quand le bouton devient « OUVRIR », l'application est installée. Appuyez dessus pour la lancer. Elle apparaît aussi automatiquement sur votre écran d'accueil.
ℹ️ Mot de passe Apple ID : si iPhone vous demande votre mot de passe Apple ID pour une application gratuite, saisissez-le — c'est normal. Si vous ne vous en souvenez plus, appuyez sur « Mot de passe oublié ? ».

💡 Bon à savoir

Une application installée depuis l'App Store peut être supprimée à tout moment en appuyant longuement sur son icône, puis sur « Supprimer l'app ». Vous pouvez toujours la réinstaller gratuitement.

Étape 1 — Ouvrir le Play Store

1
Trouvez le Play Store sur votre écran d'accueil
Le Play Store est une icône multicolore en forme de triangle « Play » (comme un bouton lecture). Il est installé d'office sur tous les téléphones Android.
Si vous ne la voyez pas, balayez l'écran vers le haut pour afficher toutes vos applications
2
Appuyez sur l'icône pour ouvrir le Play Store
Un simple appui suffit. Le Play Store s'ouvre sur la page d'accueil.
