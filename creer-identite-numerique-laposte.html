Créer son Identité Numérique La Poste

Créez votre Identité Numérique puis connectez-vous facilement à de nombreux services en ligne.

AVANT DE COMMENCER

Ce qu'il vous faut

Pour créer votre Identité Numérique, il vous faut :

  • 🧑 Être majeur
  • 🪪 Une pièce d'identité valide
  • 📱 Un smartphone avec numéro de mobile

1. Installer l'application

Sur votre smartphone, ouvrez le magasin d'applications (App Store sur iPhone, Google Play sur Android) et recherchez « L'Identité Numérique La Poste ».

ℹ️ Attention à bien choisir cette application précise : elle est différente de l'application « La Poste » utilisée pour suivre les colis.

2. Créer son compte

Ouvrez l'application, créez un compte et saisissez les informations demandées à partir de votre pièce d'identité.

3. Vérifier son identité

Cette étape confirme que vous êtes bien la personne indiquée sur la pièce d'identité. Deux façons de procéder :

Conseillé 🏤 En bureau de poste Un conseiller vérifie votre pièce d'identité en personne. Rassurant et simple si vous n'êtes pas à l'aise avec une vérification à distance.
💻 100 % en ligne Vérification à distance directement depuis l'application, sans déplacement.
ℹ️ Les deux méthodes sont officiellement reconnues. Choisissez celle qui vous met le plus à l'aise.

4. Activer le service

Une fois votre identité vérifiée, choisissez un code secret dans l'application. Il vous servira à confirmer vos connexions. Votre Identité Numérique est valable 5 ans.

UTILISER SON IDENTITÉ NUMÉRIQUE

Utiliser FranceConnect

Une fois créée, voici ce qui se passe à chaque fois que vous l'utilisez pour vous connecter (par exemple avec FranceConnect).

Vous recevez une notification

Une notification apparaît sur votre téléphone

Ouvrez cette notification pour accéder à l'application.

Confirmer que c'est bien vous

L'application demande si vous êtes à l'origine de cette connexion

Si c'est bien vous qui êtes en train de vous connecter, appuyez sur Confirmer.

⚠️ Soyez vigilant : ne confirmez jamais une demande si quelqu'un vous l'a demandé par téléphone. Une confirmation ne se fait que si vous-même êtes en train de vous connecter à un service.

Saisir votre code secret

Saisissez le code secret choisi lors de l'activation

Identification réussie

Vous pouvez retourner sur votre navigateur, la connexion est validée

Retournez sur la page où vous étiez : vous êtes maintenant connecté.

🔒 Votre code secret est strictement personnel. Ne le communiquez à personne, y compris à un interlocuteur qui se présente comme un conseiller La Poste ou des impôts.
