Se connecter avec FranceConnect

Beaucoup de sites administratifs proposent de vous connecter avec FranceConnect. Voici comment ça fonctionne, sans confusion.

De quoi avez-vous besoin ?

Pour utiliser FranceConnect, il vous faut simplement un compte que vous possédez déjà parmi :

  • votre espace particulier impots.gouv.fr
  • votre compte Ameli.fr (Assurance Maladie)
  • L'Identité Numérique La Poste
  • votre compte MSA
  • France Identité
ℹ️ Le nom sur ce compte doit correspondre exactement à votre état civil. Si ce n'est pas le cas, la connexion sera refusée.

FranceConnect n'est pas un compte

C'est la confusion la plus fréquente : FranceConnect n'a pas de mot de passe. C'est une porte d'entrée commune à de nombreux sites administratifs. Une fois devant cette porte, vous choisissez le compte que vous utilisez déjà pour prouver que c'est bien vous.

🔑 Pour retenir simplement : FranceConnect, c'est le sas d'entrée. Votre compte impots.gouv.fr, Ameli ou La Poste, c'est votre badge pour passer ce sas.

Repérer le bouton FranceConnect

Ce bouton apparaît sur de nombreux sites administratifs

Sur la page de connexion d'un service en ligne (impots.gouv.fr, Ameli, service-public.fr…), repérez le bouton « S'identifier avec FranceConnect » et cliquez dessus.

Choisir votre compte

Choisissez le compte que vous utilisez déjà

Un écran vous propose plusieurs comptes. Cliquez sur celui que vous possédez déjà — par exemple « L'Identité Numérique La Poste » si c'est celui-ci que vous utilisez.

impots.gouv.fr Numéro fiscal + mot de passe
Ameli.fr Numéro de sécurité sociale + mot de passe
L'Identité Numérique La Poste Identifiants de l'application La Poste
MSA Compte de la Sécurité sociale agricole
ℹ️ Si vous êtes déjà sur le site correspondant à l'un des comptes proposés (par exemple impots.gouv.fr), cette tuile apparaît grisée : c'est normal, il est inutile de vous en resservir pour vous y reconnecter.

Se connecter avec votre compte habituel

Vous êtes redirigé vers l'écran de connexion habituel de votre compte (par exemple l'application La Poste ou le mot de passe Ameli). Connectez-vous comme vous le faites d'habitude.

Retour automatique sur le service

Une fois identifié, vous êtes renvoyé automatiquement sur le site de départ, déjà connecté. Aucune donnée bancaire n'est demandée : FranceConnect sert uniquement à vérifier votre identité.
